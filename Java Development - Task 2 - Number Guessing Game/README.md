
# Number Guessing Game

## Project Overview
A Java-based console game where the player guesses a randomly
generated number within a limited number of attempts.

## Features
- Random number generation
- Easy, Medium and Hard difficulty levels
- Limited attempts based on difficulty
- Too High and Too Low hints
- Input validation
- Play Again functionality
- Score tracking across multiple rounds

## Technologies Used
- Java
- Java Random class
- Java Scanner class
- Object-oriented programming concepts
- VS Code

## Difficulty Levels

| Level | Number Range | Maximum Attempts |
|-------|--------------|------------------|
| Easy  | 1-50         | 10               |
| Medium| 1-100        | 7                |
| Hard  | 1-200        | 5                |

## How to Run

1. Install JDK and VS Code.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Navigate to the project folder.
5. Compile the program:

   javac -d out src/NumberGuessingGame.java

6. Run the program:

   java -cp out NumberGuessingGame
